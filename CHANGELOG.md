## [0.1.0] - 2026-11-12

Initial source release.

### Added

- Native macOS menu bar app to virtually disconnect and reconnect external displays while keeping the hub connected.
- Left-click to toggle display pause; right-click to open controls for individual displays.
- Display icon with pause bars inside the screen when pause is active.
- Separate connection popup with Reconnect and Dismiss actions, including physical reconnection detection while a display remains virtually offline.
- Automatic German and English localization, with English fallback and extensible translation files.
- Optional launch at login and explicit display restoration when quitting normally.
- Built-in display protection, state verification, reconnect retries, and bounded automatic pause reapplication.
- Developer-signed local build, generated app icon, read-only diagnostics, and opt-in hardware verification.
- Automated safety, reconnect, physical connection handling, and localization tests.
- MIT license.
